## Project Overview

This project demonstrates a complete CI/CD pipeline for a Python package called **Simple HTTP Checker** - a command-line tool for checking HTTP endpoint availability.

## What implemented in this repository

- **The project (code files)** - Complete Python package with proper structure
- **GHA workflow** - Basic GitHub Actions setup and execution
- **Linting (ruff) and format checks (black)** - Code quality automation
- **Typing (mypy) and security checks (bandit)** - Static analysis and security scanning
- **Test automation** - Comprehensive test suite with pytest
- **Build Python project** - Automated package building
- **Publish the project to both TestPyPI and PyPI** - Automated package publishing on releases
